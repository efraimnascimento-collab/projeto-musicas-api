# Projeto Músicas API

Este projeto consiste em uma aplicação web completa desenvolvida com o objetivo de simular o funcionamento de um sistema real, utilizando integração entre frontend e backend.

O sistema permite cadastrar e visualizar músicas, seguindo o tema de MPB e Pop, incluindo artistas como Ariana Grande, Marina Sena, Urias, Duquesa, entre outros.

---

## Funcionalidades

* Cadastro de músicas com:

  * Nome
  * Artista
  * Categoria
  * Imagem
* Listagem dinâmica das músicas cadastradas
* Atualização automática da lista após o cadastro, sem recarregar a página
* Integração completa entre frontend e backend por meio de API REST

---

## Como Executar o Projeto

### Backend

1. Acesse a pasta:

```
backend/src
```

2. Instale as dependências:

```
npm install
```

3. Execute o servidor:

```
node server.js
```

---

### Frontend

Abra o arquivo `index.html` em um navegador.
